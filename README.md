# ML_HW2
NAME: VENKATADRI BABU SARVEPALLI
This project implements Linear Regression from scratch using both the Normal Equation and Gradient Descent.
A synthetic dataset of 200 samples was generated using the equation ( y = 3 + 4x + \epsilon ).
The Normal Equation directly computes the optimal intercept and slope using matrix operations.
Gradient Descent iteratively updates the parameters by minimizing Mean Squared Error (MSE).
The loss curve shows steady convergence over 1000 iterations.
Both methods produced nearly identical results, confirming correct implementation.
